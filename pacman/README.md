# Pacman Game

A simple Pacman game implemented in Python using pygame.

## Installation

1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

1. Run the game:
```bash
python pacman.py
```

2. Use the arrow keys to control Pacman:
   - ↑ Up arrow: Move up
   - ↓ Down arrow: Move down
   - ← Left arrow: Move left
   - → Right arrow: Move right

3. Collect all the white dots to win!

4. Avoid the red ghost - if it catches you, it's game over!

5. Press 'R' to restart after game over.

## Game Features

- Classic Pacman gameplay
- Maze navigation
- Dot collection with score tracking
- Ghost enemy with simple AI
- Win/lose conditions
- Restart functionality

Enjoy playing!
